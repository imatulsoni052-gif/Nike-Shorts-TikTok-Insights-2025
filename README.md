# Nike-Shorts-TikTok-Insights-2025
Capstone project combining SQL, Power BI, and Machine Learning to analyze Nike’s short-form video campaigns on TikTok &amp; YouTube Shorts.
Nike Shorts & TikTok Insights 2025
End-to-End Data Analytics & Machine Learning Project
🧠 Problem Statement

How can Nike optimize its short-form video strategy across TikTok and YouTube Shorts to maximize engagement, retention, and virality?

 Project Summary

This project delivers a complete data analytics pipeline to analyze and predict the performance of Nike’s short-form video campaigns.

Using SQL, Power BI, and Machine Learning, it transforms raw engagement data into actionable insights and predictive models, enabling smarter content strategy decisions.

🎯 Business Impact
Identified TikTok as Nike’s primary growth engine (~60% content share)
Discovered optimal posting time (Friday ~8 PM) for peak engagement
Found top creators drive ~40% of total views
Revealed mobile-first audience behavior (~70% completions)
Enabled pre-publishing viral prediction using ML models

👉 Result: A data-driven framework for improving campaign ROI and audience retention

🤖 Machine Learning Models
🔹 Logistic Regression — Viral Prediction
Predicts whether a video will go viral (1) or not (0)
Features include engagement velocity, timing, category, emoji usage
Evaluated using Accuracy, Precision, Recall, F1-score, ROC-AUC

👉 Business Value:
Predict content success before publishing

🔹 Linear Regression — Completion Rate Prediction
Predicts viewer retention (completion rate)
Key insight:
Shorter videos → Higher completion
Seasonal content → Higher engagement

👉 Business Value:
Optimize video length, timing, and content strategy

🔍 Key Insights
TikTok outperforms YouTube in views and engagement
Sports & lifestyle content drive higher retention
Emoji usage positively impacts engagement
Algorithm-driven feeds (For You) boost completion rates
Seasonal campaigns significantly increase performance
